## 二、按页面模块拆解可学习的优点

### 模块 1 — Hero（首屏）

#### 行业头部的共同优点

1. **一句话锁定客户**：DPR/Holder/Hensel Phelps 都在 Hero 用一句话直接定义"我是谁、为谁服务"，**绝不堆形容词**。
   - DPR: "Building Great Things"（自信但极简）
   - Holder: "We Build Mission-Critical, Hyperscale Data Centers"（直接锁客户类型）
   - Rosendin: "We Are the Largest Employee-Owned Electrical Contractor in the U.S."（数据 + 差异化）
2. **Hero 必有动态元素**：要么是工地视频/延时镜头（Skanska/Mortenson），要么是大型数据/数字滚动（Rosendin），要么是大型项目照片轮播（DPR）。**没有一家用静态照片**。
3. **下方紧贴信任锚点**：Hero 之下立刻就是"客户 Logo 墙 / 关键数据 / 资质证书"三选一，不让用户滚到第二屏才看到证据。
4. **CTA 极简**：Hero 区只有 1 个主 CTA（一般是 "View Projects" 或 "Get a Quote"），不堆 3-4 个按钮。

#### Oak Shield 可执行项

- [x] **已落地**：动态数据中心 SVG 动画 Hero（科技感拉满）
- [ ] **Hero 文案改一句话锁定**：当前文案需要打磨成"Self-Performing Mechanical & Electrical for Mission-Critical Texas Builds"这种锐利定位句
- [ ] **Hero 主 CTA 简化为 1 个**："View Signature Projects"（导向案例页），次 CTA 用低对比文字链
- [ ] **Hero 下方加 1 行关键数据条**：成立年份 / 自营工种数 / 累计交付项目数 / 持证电工人数（数据要真实，不能编）

### 模块 2 — Markets / Industries（垂直分类）

#### 行业头部的共同优点

1. **每个垂直都有"Signature Project"**：Holder/DPR 的 Markets 页面，每个行业下都标志性地挂一个**最重 Logo 项目**，配 1-2 行描述，立刻建立"我们做过这一档"的认知。
2. **Self-Performed Scope 单独列出**：Rosendin/CEI 在每个 Market 下明确写出"我们自营哪些工种、不依赖分包"，这是 B2B 甲方做技术评估时直接看的。
3. **"Adjacent Project Types"标签**：Mortenson 在每个 Market 下列 4-6 个相关项目类型小标签，告诉甲方"虽然你不是数据中心，但你那个边缘机房我们也做过"，扩大 SQL 漏斗。
4. **每个 Market 有独立 Landing Page**：Holder 的 /markets/data-centers 页面是独立 SEO 页，承接 "Texas data center MEP contractor" 这种长尾词。

#### Oak Shield 可执行项

- [x] **已落地**：5 个 Markets 都加了 Signature Project + Self-Performed Scope + Adjacent Types
- [ ] **每个 Market 拆成独立子页**（/markets/data-centers, /markets/hospitality 等）做 SEO 落地页
- [ ] **每个独立子页加 3 个内容模块**：① 该 Market 的设计/施工 Pain Point + Oak Shield 解法；② 1-2 个 Signature Project 详细 Case Study；③ 该 Market 的 Self-Perform 工种深度说明
- [ ] **每个 Market 标"Texas-only"或"Houston/Dallas/Austin"地理标签**：本地 SEO 必须打

### 模块 3 — Case Studies / Projects（案例库）

这是 Oak Shield **目前最弱的模块**，对标公司全部赢在这里。

#### 行业头部的共同优点

1. **案例必有"硬数据"**：Rosendin/CEI 的每个案例页都有：项目电压等级、kW/MW 总容量、平方英尺、施工周期、Self-Perform 工种清单、关键技术挑战。**没有数据的案例不要发**。
2. **结构化叙事模板**：DPR/Holder 的案例页都按 "The Challenge → The Approach → The Outcome" 三段式写，**不是流水账**。
3. **案例分类筛选**：Rosendin 案例库有 Filter（按 Market / 按 Service / 按 Region），让甲方采购员能快速找到"和我项目类似的"。
4. **关键照片有要求**：施工中航拍、配电室成片镜头、管道布置近景——**不是纯成品照**，要有"我们干活的"画面感。
5. **客户引语**：每个案例下挂 1 句甲方/总包/工程师的 Testimonial（带姓名+职位+公司，必须有授权）。

#### Oak Shield 可执行项

**案例页结构标准化（每个案例必须包含的字段）：**

```
Project Name
Client / End Owner
Location (City, TX)
Total Sq Ft / MW Capacity / Voltage Class
Project Type Tags
Self-Performed Scope (具体工种清单)
Construction Duration (start - finish month)
Key Technical Challenges (3-5 条，不写空话)
Solution Approach (Oak Shield 怎么解决)
Outcomes / Metrics (能发的数据：能源效率、按时交付率等)
Photo Gallery (施工中 + 成片，至少 6 张)
Client Testimonial (1 段引语，带 attribution)
```

- [ ] **优先把 4 个签名案例做完整**：NVIDIA Dallas / Costco Stafford / Blossom Hotel Houston / OCM Mushroom Cold Storage（每个按上述模板填）
- [ ] **再补 8-10 个二线案例**填满案例库（即使是较小的项目，结构化展示也能撑起规模感）
- [ ] **照片素材清单**进入素材采购列表（航拍 + 配电室 + 管道 + 关键设备特写 + 团队工作中）
- [ ] **客户授权**：每个案例需要的客户/甲方书面授权——参考下文"授权事项"清单

### 模块 4 — About / Differentiation（差异化定位）

#### 行业头部的共同优点

1. **数据驱动的 About 页**：Rosendin 的 About 页核心是 4 个大数：员工数 / 持有股份比例 / 全美项目数 / 累计装机容量。**不写"专业、敬业、创新"这种废话**。
2. **Self-Perform 单独成段**：CEI/Comfort Systems 都把"我们自营施工 vs 转包"作为独立 Section 重点强调，因为这是 B2B 甲方采购最关心的差异点。
3. **安全文化数据化**：DPR/Holder 都展示 EMR（Experience Modification Rate）、TRIR（Total Recordable Incident Rate）等**保险行业可验证的数字**——这比写"Safety First"管用 100 倍。
4. **创始团队履历真实可查**：Hensel Phelps 把核心管理层每个人的 LinkedIn / 行业证书 / 项目履历都列出来——B2B 甲方会查证。
5. **公司证书墙**：所有 A 档公司都有一个"Certifications & Affiliations"区，列 ABC/AGC/NECA/SMACNA/USGBC 等行业协会徽章。

#### Oak Shield 可执行项

- [ ] **About 页核心数据 4-6 个**（举例，需老板填真实数）：成立年份 / 累计 Self-Perform 项目 / Texas-licensed 持证人员数 / EMR 评分 / 累计装机容量 MW / 累计交付平方英尺
- [ ] **专门做一个"Why Self-Performed"页面**：解释 Oak Shield 为什么自营机械+电气，对甲方的价值（进度可控/质量统一/成本透明/责任不甩锅）
- [ ] **创始团队/核心管理介绍**：至少 3-5 人，每人要有真实照片、Texas Master License/PE 证书、代表项目
- [ ] **资质墙**：列出所有持有的 Texas State License / TDLR / 行业协会会员资格 / 保险等级
- [ ] **安全数据**：如果 EMR 低于 1.0（行业平均），必须放出来——这是数据中心/工业甲方招标的硬性筛选条件

### 模块 5 — Trust / Social Proof（信任建立）

#### 行业头部的共同优点

1. **客户 Logo 墙是标配**：所有 A/B/C 档公司首页都有，但**Logo 必须是真实甲方授权使用的**，不能放占位符。
2. **Awards / Recognition 单独区**：ENR Top 列表、AGC 奖项、ABC Excellence Award 等，**第三方颁奖**比自吹自擂强。
3. **行业关系网展示**：Holder 会展示主要合作的 GC/Owner（Equinix/Microsoft/Meta 等），这相当于背书链。
4. **媒体曝光**：CEI/Rosendin 会在 News 区列出他们被 Bisnow / DataCenterDynamics / ENR 等行业媒体报道的链接。

#### Oak Shield 可执行项

- [x] **已落地**：Logo 墙占位（NVIDIA/Costco/Blossom/OCM）+ "PENDING AUTH"标记
- [ ] **走完客户 Logo 授权流程**（参见"授权事项"章节）
- [ ] **Awards 区**：盘点 Oak Shield 拿过的所有协会奖项、安全奖、客户 Excellence 评级
- [ ] **News / Press Mentions 区**：把所有行业媒体报道、采访、活动出场链接归集
- [ ] **合作伙伴 Logo 墙**：除甲方外，主要 GC、设计院、设备品牌（Carrier/Trane/ABB/Schneider 等）也列出来

### 模块 6 — Conversion（转化路径 / B2B 接单设计）

#### 行业头部的共同优点

1. **多通道分流**：所有头部网站都把"询价"细分成多个入口：General RFP / Bid Submission / Career / Vendor / Press。**避免 1 个邮箱大杂烩**。
2. **专门的 Estimating / Pre-Construction 子页**：DPR/Holder 都有专门的"早期参与"宣传页，告诉甲方"在设计阶段就介入比中标后再优化更省钱"——这是引高质量客户的核心钩子。
3. **Bid Calendar / Project Pipeline**：部分公司展示当前正在投标/施工的项目状态——这本身就是"我们活很多"的证明。
4. **Career 页面做大**：所有 A 档公司都把 Career 做成网站第二大模块——MEP 行业极度缺人，能招到人的公司本身就是甲方信任的标志。

#### Oak Shield 可执行项

- [ ] **联系方式细分**：① RFP / Bid Inquiry → estimating@ ② Project Inquiry → projects@ ③ Career → careers@ ④ Vendor → vendors@ ⑤ Press → media@
- [ ] **专门的"Pre-Construction Services"页**：宣传"在设计阶段介入"的价值——这能从总包手里抢到甲方直签
- [ ] **"Working with Us" 页**：写清楚 Oak Shield 的合作流程：RFI → Site Visit → Proposal → Contract → Construction → Commissioning → Warranty
- [ ] **Career 页面做扎实**：列出当前空缺岗位、持证电工招聘、Apprenticeship Program、福利包——这反映公司活力
- [ ] **重要项目类型设独立 Lead Capture 表单**：例如 "Data Center MEP Inquiry" 表单字段比通用表单更精细（项目位置/MW 容量/Schedule Window/Owner Type）

## 三、视觉与交互层面的共同特征（D 档参考）

### 共性优点

1. **Ink-Bg + 高对比配色**：DPR/Holder/Skanska 都偏深色调（深海军蓝/碳灰），点缀工业橙或电气黄，**绝不用浅色温柔风**。Oak Shield 当前色板（Ink #0B1220 + Safety Orange）方向正确。
2. **Inter / Manrope / IBM Plex 类无衬线字体**：所有 A/B 档都用工业感等宽或紧凑无衬线字体，不用衬线字体，不用 Display 字体。
3. **大留白、大图、低密度**：Hensel Phelps/Mortenson 的页面留白极大，每屏只讲 1 件事，文字密度刻意压低。
4. **数据卡片 Hover 微交互**：Rosendin/Holder 的数据卡片、Markets 卡片、案例卡片都有 Hover 时的微动效（边框亮起 / 数据轻微 Counter Up / 浮起阴影），但**不滥用动画**。
5. **页面顶部 Sticky Nav**：所有头部网站都用 Sticky 顶部导航，且滚动后 Nav 颜色从透明变实色——便于深度阅读时随时跳转。
6. **Footer 极重**：所有头部公司 Footer 都是"小型 Sitemap"，包含 5-7 列链接（Services/Markets/Projects/Company/Career/Resources/Contact），**比一般公司大 3 倍**。

### Oak Shield 可执行项

- [x] **配色与字体方向正确**（已落地）
- [ ] **统一 Hover 微交互规则**：所有数据卡片、Markets 卡片、案例卡片用同一套 Hover 状态（边框亮 #E26B2C / 阴影上浮 / 文字浮现）
- [ ] **顶部 Nav 加 Sticky + 滚动变色**逻辑
- [ ] **Footer 重做**：当前 Footer 太轻，应扩成 5 列：Services / Markets / Projects / Company / Resources，每列 4-6 个链接
- [ ] **页面统一过渡**：标准 transition: 250ms cubic-bezier(0.4, 0, 0.2, 1)

## 四、绝对不要抄的反面教材（避坑）

1. **不要抄 Turner/AECOM 的"国际范儿"**：Oak Shield 是 Texas 区域专精公司，硬装"全球品牌"会失真，反而失去本地认同。**坚持 Texas-First 定位**。
2. **不要抄 Plumbing Webmasters 类小型水电工 B2C 网站**：Live Chat 弹窗、Coupon、"Same-Day Service"这套 B2C 玩法跟 B2B 商业项目客户期望完全不匹配。
3. **不要堆"我们提供哪些服务"长清单**：Oak Shield 当前网站犯过这个错——80% 篇幅在自夸服务范围，0% 在证据。**每写一句服务必须配一个数字或案例**。
4. **不要做 Animated Background 视差滚动满天飞**：Mortenson/DPR 的动画都是节制的，**只在 Hero 一处用强动画**，其他模块以静态为主。
5. **不要抄"虚拟设计"/"创新实验室"这类大公司讲故事的概念**：Oak Shield 没这个体量去支撑这些故事，会被甲方一眼看穿。**讲真实做过的事，比讲愿景更有力**。

## 六、一句话总结（合伙人对老板说的话）

> Oak Shield 现在的 Mockup 已经把"科技感品牌外壳"做到 70 分（动态数据中心 Hero + Logo 墙 + Markets 结构化）。
>
> 接下来 90% 的优化收益不在视觉，**在于把"Self-Perform 工种深度 + 真实案例硬数据 + 客户/资质背书"这三件事填实**。
>
> 这正是 TDIndustries / Rosendin / CEI 这一档对标公司真正赢的地方——**不是网站做得花，而是网站背后真有东西**。
>
> 视觉再好也只能锁住前 10 秒注意力；要让甲方采购员决定打电话过来，必须靠"真实硬数据 + 真实案例 + 真实人"。
